# Figma Template Frames

This folder contains simple SVG frame templates that mimic high-fidelity Figma frames for design and engineering handoff. They are intended as starting points and can be imported into Figma (File → Import) or opened directly in a browser.

Files included:
- SidePanel_Attached.svg — 1440×900, main view with an attached client state
- SidePanel_Detached.svg — 1440×900, side panel open with no client
- BottomBar_Default.svg — 1440×900, bottom bar full-width example
- BottomBar_Narrow.svg — 600×200, narrow responsive variant
- Toolbar_Normal.svg — 1440×120, toolbar with Run button filled
- Toolbar_Launching.svg — 1440×120, Launch in loading state
- QuickAccessMenu_Closed.svg — 600×400, pinned tab closed
- QuickAccessMenu_Open.svg — 600×600, quick access menu open

Export guidance:
- Desktop frames: 1440×900 (1x) — export @2x for assets if needed.
- Closeups: 600×200 (bottom bar), 600×120 (toolbar) — use SVGs for icons.
